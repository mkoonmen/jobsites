Field Hub

The website side of your Field Hub app. Leads, job sites and notes you add here show up on your iPhone within a few seconds, and what you log on the phone shows up here.

This page holds no data of its own. Your data stays in your private GitHub repository mkoonmen/fieldhub-data, so this browser needs a key to open it. You do this once per browser.

  1. Open GitHub: new fine-grained token (sign in if asked).
  2. Under Repository access pick Only select repositories and choose fieldhub-data.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  4. Press Generate token, copy it, and paste it below.

The token is saved only in this browser and is sent only to GitHub. It can open that one repository and nothing else. You can remove it any time from the Activity tab here, or delete it on GitHub.
